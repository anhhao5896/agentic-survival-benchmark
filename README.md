\# Agentic LLMs for automated survival analysis



Code, prompts, reference solutions, and agent logs for:

"Agentic large language models for automated survival analysis in R, Python, SAS, and Stata" (under review).



\## Contents

\- prompts/: agent prompt and data dictionary

\- scripts/: Inspect AI task definitions, custom tools, and execution scripts

\- reference\_solutions/: reference code in R, Python, Stata, and SAS

\- logs/: Inspect AI evaluation logs



\## Data

The colon cancer dataset is available in the R survival package and the Rdatasets repository.



\## Requirements

R 4.5.1, Python 3.11.13, StataNow 19, SAS 9.4, Inspect AI 0.3.245
